Interior PMSM (IPMSM) Field-Oriented Control Suite

Dynamic Modeling, MTPA Trajectory, and Current Regulation Benchmark

IPMSM Voltage Equations

In the synchronous \(dq\)-reference frame:

$$\begin{aligned} v_d &= R_s i_d + L_d \frac{di_d}{dt} - \omega_e L_q i_q \\ v_q &= R_s i_q + L_q \frac{di_q}{dt} + \omega_e (L_d i_d + \lambda_{pm}) \end{aligned}$$

Electromagnetic Torque & MTPA

Electromagnetic torque generated by reluctance and PM interaction:

$$T_e = \frac{3}{2} p \left[ \lambda_{pm} i_q + (L_d - L_q) i_d i_q \right]$$

Because \(L_q > L_d\) in IPMSM, reluctance torque is utilized by setting \(i_d < 0\). Maximum Torque Per Ampere (MTPA) condition dictates:

$$i_d = \frac{\lambda_{pm}}{2(L_q - L_d)} - \sqrt{\frac{\lambda_{pm}^2}{4(L_q - L_d)^2} + i_q^2}$$

System Parameters

  • Stator Resistance (\(R_s\)): 0.285 \(\Omega\)
  • d-axis Inductance (\(L_d\)): 3.0 mH
  • q-axis Inductance (\(L_q\)): 5.8 mH
  • PM Flux Linkage (\(\lambda_{pm}\)): 0.175 Wb
  • Pole Pairs (\(p\)): 4

Current Control Techniques

Select a control strategy to view formulation and execution principles

1. Proportional-Integral (PI) Field-Oriented Control

Decouples the \(d\)- and \(q\)-axis current loops using feedforward cross-coupling compensation, driving standard SVPWM switching.

// Pseudo-code: Synchronous Frame PI Controller with Decoupling
e_id = id_ref - id_meas;
e_iq = iq_ref - iq_meas;

// PI Integral Accumulation
integ_d += e_id * Ki * Ts;
integ_q += e_iq * Ki * Ts;

// Decoupled Output Voltages
vd_ref = (Kp * e_id + integ_d) - (w_e * Lq * iq_meas);
vq_ref = (Kp * e_iq + integ_q) + (w_e * (Ld * id_meas + lambda_pm));

Key Characteristics:

  • Switching Frequency: Fixed (determined by PWM carrier frequency).
  • Pros: Simple implementation, low current ripple, standard tuning rules.
  • Cons: Limited dynamic bandwidth compared to predictive methods, sensitive to cross-coupling delays.

2. Hysteresis Current Control

Direct non-linear control operating in the stationary \(\alpha\beta\) or phase \(abc\) frame. Inverter switching signals are triggered directly when phase errors cross upper/lower thresholds (\(h\)).

// Phase A Hysteresis Logic
err_ia = ia_ref - ia_meas;

if (err_ia > +h) {
    Switch_A = HIGH; // Apply positive voltage state
} else if (err_ia < -h) {
    Switch_A = LOW;  // Apply negative voltage state
}

Key Characteristics:

  • Switching Frequency: Variable (depends on operating speed, load, and inductance).
  • Pros: Extremely fast transient response, parameter independent, no modulator required.
  • Cons: High current ripple, variable acoustic noise, difficult filter design.

3. Finite Control Set Model Predictive Control (FCS-MPC)

Uses discrete-time state equations of the IPMSM to evaluate all 7 unique voltage vectors (\(V_0 \dots V_7\)) of a 2-level VSI, selecting the vector that minimizes a predefined cost function \(g\) at step \(k+1\).

$$\hat{i}_d(k+1) = i_d(k) + \frac{T_s}{L_d} \left[ v_d(k) - R_s i_d(k) + \omega_e L_q i_q(k) \right]$$ $$\hat{i}_q(k+1) = i_q(k) + \frac{T_s}{L_q} \left[ v_q(k) - R_s i_q(k) - \omega_e (L_d i_d(k) + \lambda_{pm}) \right]$$ 
// Cost Function Optimization Loop
g_opt = INFINITY;
best_vector = 0;

for (int v = 0; v < 8; v++) {
    // 1. Predict currents id_next, iq_next for switching vector v
    predict_currents(v, &id_next, &iq_next);
    
    // 2. Evaluate Cost Function
    g = pow(id_ref - id_next, 2) + pow(iq_ref - iq_next, 2);
    
    // 3. Select Vector with Minimum Error
    if (g < g_opt) {
        g_opt = g;
        best_vector = v;
    }
}
apply_inverter_vector(best_vector);

4. Deadbeat Current Control (DBCC)

A predictive model-based control technique that calculates the exact reference voltage required to force phase currents to match their command values at the end of the next sampling period (\(k+1\)).

$$v_d^*(k) = R_s i_d(k) + \frac{L_d}{T_s} \left[ i_d^*(k+1) - i_d(k) \right] - \omega_e L_q i_q(k)$$ $$v_q^*(k) = R_s i_q(k) + \frac{L_q}{T_s} \left[ i_q^*(k+1) - i_q(k) \right] + \omega_e (L_d i_d(k) + \lambda_{pm})$$

Key Characteristics:

  • Pros: Fastest possible dynamic response for fixed-frequency digital controllers.
  • Cons: Highly sensitive to parameter mismatch (\(R_s, L_d, L_q, \lambda_{pm}\)); requires model mismatch compensation or observers.

5. Sliding Mode Control (SMC)

A robust non-linear control strategy. Sliding surfaces are defined on current tracking errors, and switching controls force the state trajectories to slide along the manifold despite parameter variations.

$$s_d = i_d^* - i_d, \quad s_q = i_q^* - i_q$$ $$v_d^* = v_{d,eq} + K_d \text{sgn}(s_d), \quad v_q^* = v_{q,eq} + K_q \text{sgn}(s_q)$$ 
// Sliding Surface Evaluation
s_d = id_ref - id_meas;
s_q = iq_ref - iq_meas;

// Reaching Law using Saturation Function (to reduce chattering)
vd_ref = vd_eq + Kd * sat(s_d / boundary_layer);
vq_ref = vq_eq + Kq * sat(s_q / boundary_layer);

Key Characteristics:

  • Pros: High robustness against inductance changes, magnetic saturation, and load disturbances.
  • Cons: High-frequency chattering phenomenon (mitigated by using continuous boundary layer approximations).
